### 如何更新

与往常一样，您可以使用以下任一命令更新您的机器人：

#### docker-compose

```bash
docker-compose pull
docker-compose up -d
```

#### 通过安装脚本安装

```
# Deactivate venv and run 
./setup.sh --update
```

#### 纯原生安装

```
git pull
pip install -U -r requirements.txt
```
